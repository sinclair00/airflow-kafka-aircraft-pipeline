# Snowflake Setup

This project loads curated aircraft maintenance data into Snowflake for warehouse-based analytics.

## Objects

- Database: AIRCRAFT_MAINTENANCE_DB
- Schema: RAW
- Warehouse: AIRCRAFT_WH
- Table: RAW.CURATED_MAINTENANCE_EVENTS

Setup SQL is stored in `docs/sql/snowflake_setup.sql`.

## Load Flow

Curated CSV output generated by Airflow is loaded into Snowflake using `scripts/load_to_snowflake.py`.
